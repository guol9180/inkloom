# Security Policy

## Reporting

Do not open a public issue for a vulnerability. Use GitHub private vulnerability reporting after the public repository is created. A dedicated security contact is still TODO.

## High-Risk Areas

- Markdown HTML and SVG injection
- Mermaid and Excalidraw rendering
- Path traversal and symbolic links
- File overwrite and revision recovery
- Workspace access control and share links
- WebSocket authorization

## Supported Versions

Only the latest main-branch prototype is supported until the first stable release.
